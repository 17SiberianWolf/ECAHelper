# ECAHelper 工时统计分析 · 用户使用手册

> 适用版本：v1.0 ｜ 形态：本机本地 Web 应用（单人使用，离线可用）
> 用途：把公司每月下发的 Excel 工时表（Timesheet）导入持久化，按**项目号 / 人员 / 时间段 / 组织 / 成本中心**做多维检索统计与导出，替代手工求和。

---

## 1. 应用简介

ECAHelper 把分散在 40+ 个 Excel 工时表里的明细行统一入库，提供：

- **多维查询**：按项目号查工时、按人员查工时、跨组织/成本中心/任务的综合检索。
- **三层结果展示**：每个查询都给出「总计 → 按月 → 按人」三级汇总，并支持 **WBS 编号下钻**。
- **图表**：按月趋势、Top N 排行、人员 × 项目交叉矩阵（原生 SVG 渲染，离线可用，无外部依赖）。
- **数据质量面板**：空项目号、重复行、异常行、0 工时行、姓名变体一目了然，可勾选从统计中排除并持久化。
- **中英双语导出**：Excel / CSV，表头同时给出中英文，便于向你德国老板汇报。

| 关键口径（务必知晓） | 说明 |
|---|---|
| 时间来源 | **文件名中的年月**是唯一权威时间（如 `Timesheet of 2023.6 including SC.xlsx` → 2023-06）。表内 From/To 与游离日期列不可信，已被忽略。 |
| 空项目号行 | 在「项目维度」被排除；在「人员维度」保留为**非项目工时**，按任务细分（Leave / Procurement services / 其他）。 |
| 重复 / 异常行 | **只标记、不删除**，默认仍计入统计；可在质量面板勾选排除。 |
| 人员口径 | 以 **Resource ID** 归一化（大写、去空格）为主键；姓名仅作别名。空 Resource ID 归入 `__UNKNOWN__` 桶。 |
| 多 ID 不自动合并 | `WATA` 与 `WATA02` 视为**不同人**，系统不会自动合并。 |

## 2. 快速开始：启动应用

### 2.1 环境要求
- Windows 本机，已安装 Python 3.13（本机托管运行时已就绪）。
- 首次运行需联网一次，用于安装 `flask` / `waitress` / `openpyxl`（已写入 `requirements.txt`）。

### 2.2 一键启动
1. 进入应用目录 `ECAHelper\`。
2. **双击 `start.bat`**。
   - 它优先用本地虚拟环境（`.venv`）启动；若该环境缺失或 Flask 损坏，会自动回退到已装好依赖的托管运行时——**即使离线也能起**。
   - 程序会绑定 `http://127.0.0.1:5000/`（端口被占用时自动 +1，如 5001），并自动打开浏览器。
3. 看到首页「数据导入」即启动成功。

> 若首次启动提示缺依赖，先双击 `setup_env.bat` 联网安装依赖，再双击 `start.bat`。

### 2.3 数据已预导入
本机 `eca_helper.db` 已包含 **2023.02–2026.09 全部 44 个月、33,015 行**工时数据，启动后可直接查询。
如需重新导入或追加新月份，到「数据导入」页点击**开始导入（全部文件）**即可（同名文件默认跳过，重复导入不会翻倍）。

## 3. 界面导航

顶部导航含 5 个页面：

| 导航 | 地址 | 作用 |
|---|---|---|
| 数据导入 | `/` 或 `/import` | 导入/刷新 Excel 工时表，查看导入报告 |
| 项目工时查询 | `/project` | 按项目号 + 时间区间统计工时 |
| 员工工时查询 | `/employee` | 按资源号/姓名 + 时间区间统计工时（含非项目工时） |
| 综合检索 | `/search` | 叠加组织 / 成本中心 / 任务等多条件检索 |
| 数据质量面板 | `/quality` | 查看数据问题，勾选排除并持久化 |

## 4. 功能详解

### 4.1 数据导入
- 页面显示数据目录（默认 `OriginSource\`）。
- 点击**开始导入（全部文件）**：扫描目录下全部 `.xlsx`，自动跳过 `~$` 锁文件与「在管项目」主数据；按文件名解析报告月份；执行去重与异常标记；维护人员表。
- 导入完成后显示报告：新增行数、跳过文件、重复行数、异常行数、0 工时行数。
- **幂等**：同名文件再次导入默认跳过（也可在接口层选择 `overwrite` / `copy`）。

### 4.2 项目工时查询
1. 选择**项目号**（下拉框，按工时从高到低）。
2. 设置**报告月份 起 / 止**（也可用快捷按钮：**今年 / 去年 / 全部 / 当前季**）。
3. 可选填 **WBS 下钻前缀**（留空看第一级；填 `A.B` 看其下一级汇总）。
4. 点**查询**，结果分两个标签页：
   - **三层结果**：
     - 总计：总工时、行数、涉及人数、涉及月数；
     - 按月：各月工时（缺月自动补 0，趋势图不断裂）；
     - 按人：每人工时明细（从高到低）。
   - **图表**：按月趋势（折线）、人员 Top N（柱状，可切换维度：人员/项目/组织/成本中心，N=5/10/20/50）、人员 × 项目交叉矩阵（热力图）。
5. 底部**导出**：选格式（Excel/CSV）与语言（中英/EN/中文），导出当前查询。

### 4.3 员工工时查询
1. 选择**资源号**，或直接在「或输入姓名/别名」框输入（如 `Li, Bo` 或 `WAXI`，系统自动解析到对应 Resource ID）。
2. 设置时间区间（同样有快捷按钮）。
3. 点**查询**：
   - 总计 = 项目工时 + 非项目工时；
   - **按项目**：该员工在各项目的工时；
   - **非项目工时**：按任务细分（Leave / Procurement services / 其他空白），便于汇报非生产性时间。
4. 图表标签页提供按月趋势与项目 Top N。

### 4.4 综合检索
在「项目/员工查询」之外，叠加更多维度：
- **组织**（下拉）、**成本中心**（下拉）、**任务**（文本，可选）；
- 勾选**含空项目号行**可把非项目工时也纳入本次检索。
- 结果同样为「三层结果 + 图表 + 导出」。

### 4.5 数据质量面板
- 顶部四个开关，勾选即把对应类别**从所有统计中排除并持久化**（写入数据库，下次查询自动生效）：
  - 排除重复行
  - 排除异常行（Actuals 被存成日期型的 14 行，如 `1900-01-16`）
  - 排除 0 工时行
  - 排除空资源号行
- **默认全部不勾选**：统计包含全部原始行（保留标记、不删除），符合「标记不删」原则。
- **明细下钻**：选类别点「查看明细（最多 500）」可逐行溯源（含源文件、源行号，便于回查原表）。

### 4.6 图表说明
- 全部图表为**原生 SVG** 渲染，无任何 CDN / 外部库依赖，离线完全可用。
- 三种图表：按月趋势（折线）、Top N 排行（柱状，维度/数量可调）、人员 × 项目交叉矩阵（热力图，工时合计与三层结果一致）。

### 4.7 导出
- 位置：各查询页底部「导出」区，导出**当前查询条件**下的结果。
- 格式：Excel（`.xlsx`）/ CSV（`.csv`）。
- 语言：中英双语表头（如 `Project ID / 项目号`）、仅英文、仅中文。
- 文件名规则：`导出_<类型>_<YYYYMMDD_HHMM>.<xlsx|csv>`，落在 `data/exports\` 目录。

## 5. 常见注意事项（向德国老板汇报前请核对）

1. **月份以文件名准**：若某月文件改名或月份写错，请以文件名为准修正后重新导入。
2. **非项目工时**：汇报某人总投入时，项目工时 + 非项目工时（Leave/Procurement 等）才是全貌；非项目工时只在「人员维度」出现，不会混入「项目维度」排行。
3. **重复/异常**：默认计入统计。若你希望汇报「去重后有效工时」，到质量面板勾选「排除重复行 / 排除异常行」并保存。
4. **WATA 与 WATA02**：系统视为两个不同的人，不会合并；如需合并请在质量面板手动处理（本期为手动，不自动）。
5. **数据隐私**：`OriginSource\` 含员工原始工时表，`eca_helper.db` 与 `data/exports\` 为派生数据，均已加入 `.gitignore`，请勿随代码仓库外发。
